Ganti warna bawaan lewat kode

Ubah OL_DEFAULTS di assets/js/orulabs-theme-init.js:

var OL_DEFAULTS = {
    primary: "#7c3aed",   // warna utama
    mode: "light",        // light | dark | auto
    sidebar: "dark",      // light | dark | primary
    radius: "14",         // 6 | 14 | 20
    mini: false
};

Atau ganti dari JavaScript kapan saja:

OL.setTheme({ primary: "#16a34a", sidebar: "primary" });
